# Genie Space Data Dictionary

To get the best text-to-SQL performance from your Databricks Genie space, you should copy and paste these descriptions directly into the **Comments** section of the columns in **Catalog Explorer**, or provide them in the **Genie Space Instructions**.

## Table: `facility_records`

**Table Description:** Contains detailed, row-level profiles for individual healthcare facilities, NGOs, and medical centers in Ghana.

| Column               | Description for Genie / SQL                                                                                                                               |
| :------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `facility_id`        | Unique UUID identifier for the healthcare facility or organization.                                                                                       |
| `facility_name`      | The official name of the hospital, clinic, or NGO.                                                                                                        |
| `organization_type`  | Broad classification of the entity. Valid values are exactly: `facility` (for physical healthcare centers) or `ngo` (for non-governmental organizations). |
| `specialties`        | Array of strings representing specific medical specialties practiced at the facility (e.g., Cardiology, Pediatrics). Can be used with `array_contains()`. |
| `procedures`         | Array of strings representing specific medical procedures or operations performed.                                                                        |
| `equipment`          | Array of specific medical hardware or equipment available at the facility (e.g., MRI, X-Ray).                                                             |
| `capabilities`       | Array of general operational capabilities or services offered.                                                                                            |
| `address_line1`      | Primary street address details for the facility.                                                                                                          |
| `address_line2`      | Secondary street address details.                                                                                                                         |
| `address_line3`      | Additional street address details.                                                                                                                        |
| `city`               | The specific city or town where the facility operates.                                                                                                    |
| `state`              | The administrative region or state (e.g., 'Greater Accra', 'Ashanti', 'Western North'). Often used for geographic filtering.                              |
| `country`            | The country of operation. Universally set to 'Ghana'.                                                                                                     |
| `country_code`       | Two-letter ISO country code.                                                                                                                              |
| `latitude`           | Geospatial latitude coordinate. Null if exact location is unknown.                                                                                        |
| `longitude`          | Geospatial longitude coordinate. Null if exact location is unknown.                                                                                       |
| `phone_numbers`      | Array of contact telephone numbers for the facility.                                                                                                      |
| `email`              | Standard contact email address.                                                                                                                           |
| `websites`           | Array of all web URLs related to the facility.                                                                                                            |
| `social_links`       | Key-value map containing social media platform names and URLs.                                                                                            |
| `officialWebsite`    | The primary, official web homepage.                                                                                                                       |
| `year_established`   | Integer representing the year the facility was founded or opened.                                                                                         |
| `accepts_volunteers` | Boolean (`true`/`false`) flag indicating whether the organization accepts volunteer workers.                                                              |
| `capacity`           | Integer representing the total bed count or physical patient capacity. Null if unknown.                                                                   |
| `no_doctors`         | Integer representing the total count of doctors employed at the facility. Null if unknown.                                                                |
| `description`        | Detailed text narrative describing the background and operations of the facility.                                                                         |
| `mission_statement`  | The official mission statement or primary objective of the organization.                                                                                  |
| `affiliation_types`  | Array specifying organizational affiliations. Valid values include: `philanthropy-legacy`, `academic`, `faith-tradition`, `government`, `community`.      |
| `operator_type`      | Specifies the sector operating the facility. Valid values are exactly: `private` or `public`.                                                             |
| `facility_type`      | Specific type of healthcare facility. Valid values include: `clinic`, `hospital`, `farmacy`, `doctor` (solo practice), `dentist`.                         |
| `created_at`         | Timestamp when the record was generated by the pipeline.                                                                                                  |
| `updated_at`         | Timestamp when the record was last modified.                                                                                                              |

## Table: `regional_insights`

**Table Description:** A pre-aggregated OLAP/cube table containing metrics (facility counts, capacity, doctor counts) grouped geographically (State/City) and sliced across six operational dimensions: Overview, Operator, Facility Type, Organization, Specialty, and Affiliation.

Because this table is pre-aggregated, queries should filter exactly on insight_category and insight_value to avoid double-counting totals. For specialty and affiliation categories, total_capacity and total_doctors are always NULL by design — bed and doctor counts must not be multiplied by the number of specialties or affiliations a facility belongs to.

| Column             | Description for Genie / SQL                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| :----------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| `country`          | Target country for the aggregation slice. Universally set to 'Ghana'.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `state`            | The administrative region/state level dimension (e.g., 'Greater Accra').                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `city`             | The city-level dimension. If this is `null`, the row represents an aggregation for the **entire state**.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `insight_category` | The aggregation grouping dimension. Valid values are exactly: `overview` (global totals), `operator` (split by public/private sector), `facility_type` (split by facility_type), `organization` (split by organization_type), `specialty` (split by medical specialty), or `affiliation` (split by affiliation_type). Always filter on this column to choose the grouping context.                                                                                                                                                                 |
| `insight_value`    | The specific dimension value being grouped. Depends on `insight_category`. If category is `overview`, this is always `all_facilities`. If category is `operator`, this is `private` or `public`. If category is `facility_type`, this is `clinic`, `hospital`, `farmacy`, `doctor`, or `dentist`. If category is `organization`, this is `facility` or `ngo`. If category is `specialty`, this holds the specialty name. If category is `affiliation`, this is `faith-tradition`, `government`, `community`, `philanthropy-legacy`, or `academic`. |
| `facility_count`   | The total number of unique facilities matching this specific geography, category, and value.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `total_capacity`   | The sum of bed capacities across all facilities in this exact aggregation slice. Always NULL when `insight_category` is `specialty` or `affiliation` — bed counts must not be multiplied by the number of specialties or affiliations a facility belongs to.                                                                                                                                                                                                                                                                                       |     |
| `total_doctors`    | The sum of doctor counts across all facilities in this exact aggregation slice. Always NULL when `insight_category` is `specialty` or `affiliation` — for the same overcounting reason as `total_capacity`.                                                                                                                                                                                                                                                                                                                                        |     |
